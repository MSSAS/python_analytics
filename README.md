# Python Analytics Projects (Collection)

## Описание
Сборник учебных и исследовательских кейсов по анализу данных:
статистика, визуализация и корреляция факторов на реальных датасетах.

## Структура
- `/MathStat_Analysis` — статистический анализ данных  
- `/mini_project` — корреляции характеристик клиентов   
- `/lesson` — упражнения по Pandas и Seaborn

## Технологии
- Python (pandas, numpy, matplotlib, seaborn)
- Jupyter Notebook

## Пример анализов
1. Проверка гипотезы t‑test (различие средних)  
2. Визуализация корреляции через Heatmap  
3. Определение влияния параметров на прибыли по категориям

## Результаты
- Найдены факторы влияющие на доход (температура, категория товара, регион)  
- Освоен статистический анализ (P‑value интерпретация)  
- Подготовлены графики для финальных отчётов
